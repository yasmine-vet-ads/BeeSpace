# Recursos Visuais para hardware do BeeSpace

Este diretório contém recursos visuais gerados para a documentação e apresentações do BeeSpace.

- `esp32-s3-simulator-architecture.svg` é uma captura de tela simulada em modo escuro (16:9) de um simulador, mostrando um ESP32-S3 em uma placa de ensaio, módulos de conexão de sensores de colmeia identificados, um editor de código C++/FreeRTOS, telemetria do monitor serial e um fluxograma sobreposto, desde os sensores de colmeia instrumentados até o pipeline de backend/IA, passando por MQTT/Wi-Fi.

O arquivo SVG é gerado por `scripts/generate_esp32_simulator_architecture_svg.py`, permitindo que o layout e o texto sejam atualizados de forma reprodutível.
