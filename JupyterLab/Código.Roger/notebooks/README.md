# 💻 Notebooks BeeSpace

Os notebooks originais permanecem na raiz de `JupyterLab/Código.Roger` para compatibilidade com a trilha demonstrativa existente. Esta pasta documenta a estrutura alvo do MVP e pode receber notebooks derivados do dashboard, validações Copernicus ou experimentos de machine learning.

Sugestão de uso no hackathon:

1. Execute `mock_data/generate_demo_data.py` para gerar os artefatos CSV/NDVI.
2. Abra `00_beespace_pipeline_integrado.ipynb` para a narrativa científica completa.
3. Use o dashboard Streamlit para a apresentação ao vivo.
